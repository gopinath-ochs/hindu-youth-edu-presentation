# Hindu Philosophy & History — Interactive Learning

Three in-depth interactive essays about Hinduism, built as standalone HTML files — no frameworks, no build steps, just open in a browser.

## Pages

| File | Description |
|------|-------------|
| [`index.html`](index.html) | Landing page |
| [`vedas.html`](vedas.html) | The Vedas — origins, structure, oral tradition, gods, Upaniṣads, Bhagavad-gītā |
| [`darshanas.html`](darshanas.html) | The Six Darśanas — Hindu philosophical schools |
| [`history.html`](history.html) | Historical timeline, 2600 BCE → 1400 CE |
| [`veda-traditions.html`](veda-traditions.html) | What is Śāstra? — 18 traditions × 8 scripture categories |

## Features

- Reuters-style scrollytelling with sticky visual panels
- Animated IVC/Vedic migration map (SVG + JS)
- Recitation pattern explorer with Web Audio bell tones and Web Speech pronunciation
- Transmission chain calculator (canvas tree visualisation)
- Phonetic wave explorer — hear and see Sanskrit phonemes
- Śāstra explorer — interactive canon map across 18 Hindu traditions
- Open-access images from Wikimedia Commons throughout
- Fully responsive, no external JS dependencies
